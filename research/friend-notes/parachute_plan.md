# 🪂 PARACHUTE — The ADHD Follow-Through Engine

> **Merged concept: Parachute × Untax**
> *"Your brain locks up. Parachute gets you moving — whether it's cancelling a subscription or starting an essay."*

---

## The Unified Insight

Every competitor treats ADHD as either a **money problem** (subscription trackers) or a **productivity problem** (task managers). But ADHD users know they're the same problem:

> **You see the thing. You know you should do it. You can't start. And the longer you wait, the worse the shame gets.**

Parachute is the first app that treats **follow-through as one unified muscle** — for money deadlines AND tasks. Same brain. Same Wall of Awful. Same solution.

## The Shared Mechanics (What Makes It One App)

| Mechanic | Money Path | Task Path |
|---|---|---|
| **Capture** | Share sheet screenshot → AI extraction | "I'm frozen" → describe task |
| **Escalation** | Push → urgent push → AlarmKit alarm | Timer → "still stuck?" nudge → body-doubling intensifies |
| **Forced Decision** | Cancel / Keep / Snooze (alarm can't be dismissed) | Same: Do It Now / Break It Smaller / Snooze |
| **One-Tap Action** | Deep link to cancel page | Next micro-step appears |
| **Reward** | "$17.99 ADHD Tax Refunded" | "+1 task conquered" |
| **Scoreboard** | Total $ saved | Tasks completed + streak |
| **Widget** | "Hulu · $17.99 in 3 days" | "Essay · Step 3 of 7" |

## Tech Stack

| Piece | Choice | Why |
|---|---|---|
| iOS app | SwiftUI + SwiftData, Swift 6.4 | AlarmKit, widgets, Foundation Models are native-only |
| Min iOS | iOS 26 | AlarmKit + Foundation Models require iOS 26 |
| On-device AI | Apple Foundation Models (`@Generable`) | Free, private, offline task atomization |
| Server AI fallback | Claude via Anthropic SDK (for non-Apple-Intelligence devices) | Structured extraction |
| Payments | RevenueCat `purchases-ios` 5.91.0 | Required by hackathon |
| Local data | SwiftData | Offline-first |
| Auth | Sign in with Apple | No passwords |

> [!NOTE]
> **Removed from Untax's original stack:** Cloudflare Workers, email pipeline, D1, postal-mime, APNs server push. The email forwarding system is cut from v1. Capture is share-sheet + manual only. This dramatically reduces scope.
